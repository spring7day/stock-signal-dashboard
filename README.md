# 📊 Stock Signal Dashboard

실시간 주식 매수/매도 신호를 직관적인 신호등으로 표시하는 대시보드입니다.

## 🎯 주요 기능

- **실시간 주식 신호**: 전문가 수준의 기술적 분석을 통한 매수/매도 신호등
- **한국/미국 시장 지원**: 한국 주식, 미국 주식, ETF 모두 지원
- **기술적 지표**: RSI, MACD, 이동평균, 볼린저밴드 등
- **종목 관리**: 종목 추가/삭제 기능
- **비밀번호 보호**: 개인 정보 보호
- **반응형 디자인**: 모바일/PC 모두 지원
- **다크 모드**: 세련된 다크톤 UI

## 🚀 설치 및 사용

### 1. 비밀번호 설정

`script.js` 파일의 첫 부분에서 비밀번호를 설정하세요:

```javascript
const PASSWORD_HASH = 'your-password-here'; // 원하는 비밀번호로 변경
```

### 2. GitHub Pages 배포

1. GitHub에 새 repository 생성
2. 이 폴더의 모든 파일을 업로드
3. Settings → Pages → Source를 "main" 브랜치로 설정
4. 배포된 URL로 접속

## 📈 기술적 분석 지표

### RSI (Relative Strength Index)
- 30 이하: 과매도 (매수 신호)
- 70 이상: 과매수 (매도 신호)

### MACD (Moving Average Convergence Divergence)
- 양수: 상승 추세 (매수 신호)
- 음수: 하락 추세 (매도 신호)

### 이동평균선
- 가격 > 이동평균: 상승 추세
- 가격 < 이동평균: 하락 추세

### 볼린저밴드
- 하단 돌파: 강한 매수 신호
- 상단 돌파: 강한 매도 신호

## 🎨 신호등 시스템

- 🟢 **초록색 (70점 이상)**: 강한 신호
- 🟡 **노란색 (40-69점)**: 중간 신호
- 🔴 **빨간색 (39점 이하)**: 약한 신호

## 💡 사용 팁

1. **한국 주식**: 6자리 종목코드 (예: 005930)
2. **미국 주식**: 티커 심볼 (예: AAPL, TSLA)
3. **ETF**: 티커 심볼 (예: SPY, QQQ)
4. 신호등은 5분마다 자동 업데이트됩니다

현재는 시뮬레이션 데이터를 사용합니다. 실제 데이터를 사용하려면:

1. **Yahoo Finance API** 또는 **Alpha Vantage** API 키 발급
2. `fetchStockData` 함수 수정
3. CORS 문제 해결 (프록시 서버 사용 권장)
